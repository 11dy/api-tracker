## 요약

플레이스광고 광고그룹(LOCAL_AD)에 'ADVoost 플레이스' 설정(useAdvoost)과 연동형 소재(ADVOOST_PLACE_AD)가 추가됨. ON 설정 시 소재 자동 생성, 관련 API 제약사항(직접 등록/삭제/userLock 변경 불가) 적용.

## 원문 발췌

2026년 9월 16일, 플레이스광고에 ‘ADVoost 플레이스’ 설정과 연동형 소재(ADVOOST_PLACE_AD)가 추가됩니다. 플레이스광고 광고그룹( LOCAL_AD )의 adgroupAttrJson 에 useAdvoost (ADVoost 플레이스 사용 여부) 필드가 추가됩니다. useAdvoost 를 true 로 설정하면 스마트플레이스 업체 정보를 바탕으로 노출되는 연동형 소재( ADVOOST_PLACE_AD , type 17) 가 광고그룹에 자동으로 1개 생성됩니다. 값을 지정하지 않으면 false (미사용)로 처리되며, 기존 플레이스광고 광고그룹의 동작은 변경되지 않습니다. ADVoost 플레이스는 스마트플레이스 업체 이미지가 1개 이상 등록된 비즈채널에서만 사용할 수 있으며, 병의원 업종 비즈채널은 사용할 수 없습니다. 광고그룹 등록 POST /ncc/adgroups 요청의 adgroupAttrJson 에 useAdvoost 값을 설정합니다. 예제 Request POST /ncc/adgroups Request Body { "nccCampaignId" : "cmp-a001-06-000000001234567" , "name" : "플레이스 광고그룹1" , "adgroupType" : "LOCAL_AD" , "pcChannelId" : "bsn-a001-00-000000001234567" , "mobileChannelId" : "bsn-a001-00-000000001234567" , "dailyBudget" : 30000 , "useDailyBudget" : true , "adgroupAttrJson" : { "useAdvoost" : true } } Response Body { "nccAdgroupId" : "grp-a001-06-000000001234567" , "nccCampaignId" : "cmp-a001-06-000000001234567" , "name" : "플레이스 광고그룹1" , "adgroupType" : "LOCAL_AD" , "dailyBudget" : 30000 , "useDailyBudget" : true , "adgroupAttrJson" : "{ \" useAdvoost \" :true}" , "userLock" : false } 광고그룹 조회 GET /ncc/adgroups/{adgroupId} 응답의 adgroupAttrJson 에 useAdvoost 필드가 포함됩니다. 예제 Request GET /ncc/adgroups/grp-a001-06-000000001234567 Response Body { "nccAdgroupId" : "grp-a001-06-000000001234567" , "nccCampaignId" : "cmp-a001-06-000000001234567" , "name" : "플레이스 광고그룹1" , "adgroupType" : "LOCAL_AD" , "adgroupAttrJson" : "{ \" useAdvoost \" :true}" , "userLock" : false } 광고그룹 수정 (ADVoost 플레이스 ON/OFF) PUT /ncc/adgroups/{adgroupId}?fields=useAdvoost 요청으로 useAdvoost 값만 변경할 수 있습니다. PUT /ncc/adgroups/{adgroupId} 전체 수정 요청의 adgroupAttrJson 으로도 변경할 수 있습니다. OFF → ON 으로 변경하면 연동형 소재가 자동 생성(또는 재활성화)되고, ON → OFF 로 변경하면 연동형 소재가 OFF 처리됩니다. 예제 Request PUT /ncc/adgroups/grp-a001-06-000000001234567?fields=useAdvoost Request Body { "nccAdgroupId" : "grp-a001-06-000000001234567" , "adgroupAttrJson" : { "useAdvoost" : true } } 연동형 소재 (ADVOOST_PLACE_AD) 소재 유형( type )에 ADVOOST_PLACE_AD 가 추가됩니다. GET /ncc/ads?nccAdgroupId=... 등 소재 조회 API 응답에 포함됩니다. 연동형 소재는 별도의 소재 문안을 갖지 않으며( ad 필드는 {} ), 스마트플레이스에 등록된 업체 정보(업체명·업종·주소·이미지)로 노출됩니다. 연동형 소재는 시스템이 생성·관리하는 소재입니다. 아래 요청은 허용되지 않습니다. POST /ncc/ads 로 type: ADVOOST_PLACE_AD 소재를 직접 등록 (3840) 연동형 소재 삭제 — ADVoost 플레이스가 ON 인 동안 (3837) 연동형 소재의 userLock 변경 — 광고그룹의 useAdvoost 로만 제어됩니다 (3838) 예제 Request GET /ncc/ads?nccAdgroupId=grp-a001-06-000000001234567 Response Body [ { "nccAdId" : "nad-a001-06-000000001234567" , "nccAdgroupId" : "grp-a001-06-000000001234567" , "customerId" : 1234567 , "inspectStatus" : "APPROVED" , "type" : "ADVOOST_PLACE_AD" , "ad" : {}, "adAttr" : {}, "userLock" : false , "referenceKey" : "1234567890" , "status" : "ELIGIBLE" , "statusReason" : "ELIGIBLE" , "regTm" : "2026-09-01T00:00:00.000Z" , "editTm" : "2026-09-01T00:00:00.000Z" } ] ADVoost 플레이스 ON 광고그룹의 제약 사항 useAdvoost: true 인 광고그룹에는 아래 요청이 허용되지 않으며 400 Bad Request 가 반환됩니다. 요청 오류 코드 POST /ncc/ads — 소재 추가 3839 POST /ncc/ad-extensions — 확장소재 추가 4029 제외 검색어 등록 ( /n
