## 요약

파워링크 광고그룹(WEB_SITE)의 adgroupAttrJson에 `powerLinkAutomatedTextOptOut`(AI 요약텍스트 사용 안 함, boolean) 필드가 2026-11-18부터 추가됨. 미지정 시 false(사용)로 처리되며, 개별 필드 수정(`?fields=`)은 미지원(오류 3726)이라 전체 수정 PUT으로만 변경 가능.

## 원문 발췌

2026년 11월 18일, 파워링크 광고그룹에 ‘AI 요약텍스트’ 사용 설정(powerLinkAutomatedTextOptOut)이 추가됩니다. 파워링크 광고그룹( WEB_SITE )의 adgroupAttrJson 에 powerLinkAutomatedTextOptOut (AI 요약텍스트 사용 안 함) 필드가 추가됩니다. AI 요약텍스트는 광고주님께서 등록·제공하신 자료(광고 소재, 랜딩페이지, 비즈채널 정보 등)를 기반으로 네이버 AI 모델이 자동으로 생성하는 문구입니다. 값을 true 로 설정하면 해당 광고그룹에 AI 요약텍스트를 사용하지 않습니다(OFF) . false 이거나 값을 지정하지 않으면 AI 요약텍스트를 사용합니다(ON) . 값은 boolean( true / false )만 허용됩니다. 1 , "true" 와 같은 숫자·문자열 값을 보내면 오류(3749)가 반환됩니다. 기본값을 따로 저장하지 않으므로, 값을 지정하지 않은 광고그룹의 adgroupAttrJson 에는 powerLinkAutomatedTextOptOut 필드가 없습니다. 필드가 없으면 false (사용)로 처리됩니다. 파워링크 외 유형의
