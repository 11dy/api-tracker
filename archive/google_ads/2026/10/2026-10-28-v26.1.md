The following new features and updates were added in Google Ads API v26.1. Minor versions like v26.1 don't contain breaking changes. Features and updates Type Description Assets External promotion redemption tracking New messages, fields, enums, and error Added the immutable PromotionAsset.external_redeem_info field of type ExternalRedeemInfo to specify external redemption tracking details for a promotion: ExternalRedeemInfo.partner_promotion_id : An immutable ExternalPartnerId message that holds either an integer ( int_value ) or a string ( string_value ) ID of the promotion in the partner's system. Required when the code_source field is set to GOOGLE_GENERATED . ExternalRedeemInfo.code_type : Required and immutable. The offline promotion code type ( OfflinePromotionCodeType : SINGLE_USE_PROMOTION_CODE or MULTI_USE_PROMOTION_CODE ). ExternalRedeemInfo.code_source : Required and immutable. Also added the AssetError.PARTNER_PROMOTION_ID_TYPE_INCOMPATIBLE error code, which the API returns when the partner_promotion_id field uses a format that the account's promotion integration does not accept. Campaigns Waterfall channel prioritization and budget caps for campaign budgets New features, resource, service, fields, and enums Added support for waterfall channel prioritization and budget caps on campaign budgets, which let you control how you allocate a budget across network channels (Google Owned and Operated properties, the Search Partner Network, and the Google Display Network). For more information, see the channel prioritization and budget allocation blog post . Added the CampaignBudget.budget_network_settings field of type BudgetNetworkSettings , which holds at most one BudgetNetworkSetting message per advertising channel type ( advertising_channel_type ) in the BudgetNetworkSettings.settings field. Each setting assigns network channels ( NetworkChannelType : OWNED_AND_OPERATED , SEARCH_PARTNER , and GOOGLE_DISPLAY ) to priority tiers ( ChannelPriorityTier : TIER1 and TIER2 ) in the BudgetNetworkSetting.channel_priorities field (of type ChannelPriorityConfig ). A setting can also cap the share of the budget that secondary-tier network channels spend in the BudgetNetworkSetting.budget_caps field (of type BudgetCapConfig ). The BudgetCapConfig.cap_percent_millis field specifies the cap in milli-percent units ( 1,000 = 1% , 100,000 = 100% , and 0 = 0% opt-out). When unset, the customer-level defaults in the CustomerBudgetNetworkSetting resource apply. Added the read-only CampaignBudget.budget_network_eligibility field of type BudgetNetworkEligibility , which indicates whether a budget is eligible ( eligible ) for waterfall prioritization and budget caps and, if not, the ineligibility reasons ( ineligible_reasons of type BudgetNetworkIneligibleReason ).
