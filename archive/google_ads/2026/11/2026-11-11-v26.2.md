## 원문 발췌

The following new features and updates were added in Google Ads API v26.2. Minor versions like v26.2 don't contain breaking changes. Features and updates Type Description Assets AssetAutomationType.OVERLAY_TEXT_ON_VIDEOS New enum value Added the OVERLAY_TEXT_ON_VIDEOS enum value to the AssetAutomationType enum. This setting overlays text from associated text Asset resources (such as headlines) on top of video Asset resources. Configure this setting in the AdGroupAd.ad_group_ad_asset_automation_settings field (of type AdGroupAdAssetAutomationSetting ) for Demand Gen video responsive ads ( DemandGenVideoResponsiveAdInfo on the Ad.demand_gen_video_responsive_ad field). For new Demand Gen video responsive ads created in v26, this setting defaults to the AssetAutomationStatus.OPTED_IN status. In earlier API versions, this setting defaults to the AssetAutomationStatus.OPTED_OUT status for new ads. When you query this setting in API versions earlier than v26, the API returns the AssetAutomationType.UNKNOWN enum value. For more information, see Ad-level asset automation settings . Campaigns Seasonality adjustments for Demand Gen campaigns Expanded support Added support (in beta) for applying BiddingSeasonalityAdjustment resources to Demand Gen campaigns (see Create seasonality adjustments ): When the BiddingSeasonalityAdjustment.scope field is set to the SeasonalityEventScope.CAMPAIGN enum value, you can specify Demand Gen campaign resource names in the BiddingSeasonalityAdjustment.campaigns field. When the BiddingSeasonalityAdjustment.scope field is set to the SeasonalityEventScope.CHANNEL enum value, you can specify the AdvertisingChannelType.DEMAND_GEN enum value in the BiddingSeasonalityAdjustment.advertising_channel_types field. Demand Gen support for seasonality adjustments applies to the YouTube, Display, Gmail, and Maps inventory channels. Seasonality adjustments have no effect on the Discover channel. General Multi-Party Authorization error codes New enum values and errors Added the following error codes for Multi-Party Authorization : MutateError.MULTI_PARTY_APPROVAL_UNSUPPORTED_RESOURCE_COMBINATION : Returned by the GoogleAdsService.Mutate method when a request combines an operation that requires multi-party approval with an operation on an incompatible resource. MultiPartyAuthReviewError.STALE_MULTI_PARTY_AUTH_REQUEST : Returned by the MultiPartyAuthReviewService.ResolveMultiPartyAuthReview method when resolving a MultiPartyAuthReview resource whose target resource was modified or deleted after the review was created.
