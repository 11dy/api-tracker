## 원문 발췌

The following new features and updates were added in Google Ads API v25.2. Minor versions like v25.2 don't contain breaking changes. Features and updates Type Description Assets URL options for AssetGroup New fields Added support for URL options on AssetGroup , allowing advertisers to specify tracking templates, custom parameters, and final URL suffixes at the asset group level: AssetGroup.tracking_url_template : URL template for constructing a tracking URL. AssetGroup.url_custom_parameters : A list of mappings to be used for substituting URL custom parameter tags in tracking_url_template , final_urls , or final_mobile_urls . AssetGroup.final_url_suffix : URL template for appending parameters to landing page URLs served with parallel tracking. Campaigns Automated video crawl info New fields and enums Added AutomatedVideoCrawlSetting to Campaign.AssetAutomationSetting , along with AssetAutomationType.AUTOMATED_VIDEO_CRAWL , allowing you to specify the automated video crawl settings for a Performance Max campaign. AutomatedVideoCrawlSetting.automated_video_crawl_infos contains a list of AutomatedVideoCrawlInfo entries, each configuring a crawl url , source_platform ( VideoCrawlSourcePlatform : LANDING_PAGE , SOCIAL , or YOUTUBE ), and enabled opt-in status. Customer Lifecycle Optimization value multiplier errors New enum values and errors Added new validation error reasons when configuring value multipliers ( value_multiplier and high_lifetime_value_multiplier ) for Customer Lifecycle Optimization: GoalError : HIGH_LIFETIME_VALUE_MULTIPLIER_PRESENT_BUT_VALUE_MULTIPLIER_ABSENT HIGH_LIFETIME_VALUE_MULTIPLIER_LESS_THAN_OR_EQUAL_TO_VALUE_MULTIPLIER CampaignGoalConfigError : HIGH_LIFETIME_VALUE_MULTIPLIER_PRESENT_BUT_VALUE_MULTIPLIER_ABSENT HIGH_LIFETIME_VALUE_MULTIPLIER_LESS_THAN_OR_EQUAL_TO_VALUE_MULTIPLIER CAMPAIGN_OVERRIDE_HIGH_LIFETIME_VALUE_MULTIPLIER_NOT_SUPPORTED_FOR_CAMPAIGN_TYPE SmartCampaignSettingService.GeneratePMaxDraftCampaign New feature Added SmartCampaignSettingService.GeneratePMaxDraftCampaign to support generating a Performance Max draft campaign from an existing Smart campaign, initialized with a status of CampaignStatus.PAUSED and a creation status of CampaignCreationStatus.INCOMPLETE (see Convert smart campaigns to PMax campaigns ): Set GeneratePMaxDraftCampaignRequest.validate_only to true to validate the conversion and receive any validation warnings or conversion issues in GeneratePMaxDraftCampaignResponse.validated_info without creating the draft campaign. (Leave gbp_enabled and image_enabled unset or false ; setting them to true is not yet supported and returns SmartCampaignError.GBP_ENABLED_GENERATE_PMAX_NOT_SUPPORTED or SmartCampaignError.IMAGE_ENABLED_GENERATE_PMAX_NOT_SUPPORTED .) GeneratePMaxDraftCampaignResponse returns the resource names of the generated entities ( pmax_campaign , campaign_budget , asset_group , and assets ) along with validated_info .
